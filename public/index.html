渠道

自由添加上游渠道;点「切换」直连某个渠道,或点「路由模式」让客户端经 :8787 按规则分发(写入前自动备份)

路由

按模型名匹配(子串,逗号分隔,大小写不敏感);优先级大的先匹配,同优先级按从上到下

规则

目标可以选单个渠道,也可以选渠道池——池里的渠道按会话粘性分给不同对话, 即同一个 Agent 的多个对话各走各的 key,对话内不会中途切换。目标模型留空 = 透传;带 [1M] 后缀 = 自动剥离并附加 context-1m beta 头

默认路由

所有规则都未命中时使用;可同样配成渠道池。未绑定渠道时请求报 503

会话

每个对话锁定一个渠道;这里的改动立即对该对话生效,不影响其他对话(Claude Code 与 Codex 的对话都会出现在这里)
会话组对话渠道(可改)模型命中规则请求tokens 入/出最近活跃
还没有活跃对话经 127.0.0.1:8787 的 Claude Code / Codex 会话会自动出现在这里,并按路由策略分到不同渠道

请求日志

内存保留最近 500 条,落盘 logs/requests.jsonl(5MB 轮转);统计为内存窗口内全量聚合
